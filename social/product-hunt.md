## Description

### Main Description
QueueDesk is the AI-first, open-source helpdesk that makes support teams more productive. Built with Next.js, Supabase, and OpenAI—deploy anywhere, forever free.

Tired of:
- Paying hundreds per agent for bloated helpdesk software?
- Switching between tools to manage support tickets?
- AI features that feel like afterthoughts?

QueueDesk is different. AI is at the core of everything we do:
- **Smart Classification** – AI categorizes and routes tickets automatically
- **Ticket Summarization** – Get concise summaries of long tickets instantly
- **Suggested Replies** – AI drafts responses for agents to review and send
- **Knowledge Base Integration** – Relevant articles suggested automatically

### Key Features
✅ Three purpose-built portals:
- End-user portal for simple ticket submission
- Agent console with AI-powered productivity tools
- Admin dashboard for complete control

✅ Built for teams of 20-500 people
✅ Slack integration that actually works
✅ Multi-tenancy with enterprise-grade security
✅ Self-hostable (MIT licensed)
✅ Deploy in 5 minutes or less
✅ No credit card required, no vendor lock-in

### Tech Stack
- Next.js 16 (App Router)
- Supabase (PostgreSQL + Auth)
- OpenAI (GPT-4o)
- Tailwind CSS
- TypeScript

### Results from Beta
Teams using QueueDesk in beta saw:
- 40% faster first responses
- 30% faster ticket resolution
- 65% higher agent satisfaction

For the engineers curious about the tech: we use Next.js 16 App Router for the frontend, Supabase for auth/db/realtime, OpenAI for AI features, and everything's all TypeScript.
