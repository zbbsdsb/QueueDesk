# QueueDesk Demo Video Guide

## Video Overview

**Goal:** Create a 2-3 minute demo video that showcases QueueDesk's core features in action.

**Tone:** Energetic, professional, helpful.

**Style:** Screen recording with voiceover + on-screen captions.

- Show AI classification in action

- Show 1-click deploy to Vercel

## Recording Tips

### Technical Requirements
- **Resolution:** 1920x1080 (1080p)
- **FPS:** 60 FPS (smooth, then export to 30 FPS)
- **Format:** MP4 (H.264)
- **Audio:** Clear voiceover, light background music (optional)

### Screen Capture Setup
1. **Clean up your desktop:**
   - Close all irrelevant apps
   - Hide bookmarks bar
   - Use incognito mode for clean browser
   - Use a simple desktop background

2. **Demo data setup:**
   - Create sample tickets beforehand
   - Create sample users/teams/queues
   - Configure AI features for demo

3. **Browser zoom:**
   - Zoom to 125% for better visibility

### Voiceover Tips
- **Write a full script first**
- **Record audio separately** (then sync to video)
- **Speak clearly and slowly**
- **Use a good quality microphone**
- **Smile while recording (it comes through!)**

### Editing Tips
- **Keep cuts quick**—one scene every 10-30 seconds
- **Add on-screen captions** for accessibility and silent viewing
- **Use subtle zooms/pans** to highlight key elements
- **Add light background music** (low volume)
- **Keep total video under 3 minutes**

## Demo Checklist

### Pre-Recording Setup
- [ ] Clean up desktop and browser
- [ ] Create demo data:
  - 5-10 sample tickets (mix of open/resolved)
  - 3-5 sample users
  - 2-3 sample teams/queues
  - Sample knowledge base articles
- [ ] Test all features you plan to show
- [ ] Confirm AI features are working
- [ ] Write full voiceover script
- [ ] Do a full dry run (timing check)

### Recording
- [ ] Record in 1080p resolution
- [ ] Use clean browser profile
- [ ] Record at 60 FPS
- [ ] Record audio separately (if possible)
- [ ] Use smooth mouse movements
- [ ] Don't rush—slow down for clarity
- [ ] Pause between actions for cuts

### Post-Production
- [ ] Edit down to 2-3 minutes
- [ ] Sync voiceover to video
- [ ] Add on-screen captions
- [ ] Add subtle zooms/arrows to highlight
- [ ] Add branding (logo, colors)
- [ ] Add background music (low volume)
- [ ] Export to MP4 (H.264)
- [ ] Create thumbnail
